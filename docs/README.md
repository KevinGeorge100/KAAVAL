# KAAVAL Documentation

The documents in this directory are the approved source of truth for KAAVAL’s MVP.

## Structure

- `product/` — approved MVP scope and future product-source documents when imported.
- `architecture/` — system architecture, technology-stack decision, and future ADRs.
- `engineering/` — implementation and sprint plans, standards, testing, and release guidance.
- `privacy/` — future privacy, retention, consent, and disclosure decisions.
- `runbooks/` — future release and operational checklists.

## Current approved documents

- Product: KAAVAL MVP Scope v1.0
- Architecture: KAAVAL MVP Architecture v1.0; Technology Stack Recommendation v1.0
- Engineering: Engineering Implementation Plan v1.0; Sprint Implementation Plan v1.0

The vision and problem-statement source material was approved in the planning conversation but has not yet been imported as standalone repository files.
