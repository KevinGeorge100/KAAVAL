# KAAVAL Ecosystem - Technical Changelog

## [v1.0.0-Sprint2] - 2026-08-01

### Added
- **Malayalam TTS Support**: Integrated `ml-IN` locale and translated all emergency prompts.
- **Language Preference UI**: Added a high-contrast toggle in the Medical Profile screen.
- **Telegram Bot Integration**: Primary free alert system for instant group coordination.
- **Strict P-Gesture**: Intentional uppercase "P" drawing trigger to bypass TalkBack traps.
- **Acoustic Panic Detection**: RMS-based shout detection foundation.
- **Physical Redundancy**: Volume Up x3 "Pocket Trigger" (No-unlock required).
- **Shake-to-Activate**: Accelerometer-based emergency trigger.
- **Tactile Heartbeat**: Continuous haptic feedback for caregiver response assurance.
- **Audio Witness**: Automatic 15-second ambient recording on activation.
- **Battery Guardian**: Final location ping at 5% battery.

### Fixed
- **Audio Resource Conflict**: Resolved microphone contention between Voice Listener and Audio Recorder.
- **TalkBack Intercepts**: Replaced single-tap buttons with gestural/physical triggers for emergency actions.
- **Permission Management**: Implemented runtime flow for Location, SMS, Audio, and Bluetooth.
- **Wearable Logic**: Fixed "Zombie" battery data display on disconnected devices.
