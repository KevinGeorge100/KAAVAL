Troubleshooting: Seeing "App not installed"?

Directly downloaded applications that use accessibility features for hardware triggers can encounter standard Android installation checks. If installation halts, follow these steps:

1. Google Play Protect Scan

Play Protect may block direct sideloading of apps containing background accessibility listeners.

Resolution: Open Google Play Store → tap your Profile icon → Play Protect → tap the Settings gear (⚙️) → temporarily turn off Scan apps with Play Protect, then install the APK.

2. File Manager Installation Permission

If installing from your phone's Files or Downloads folder, your file manager must have permission to install unknown apps.

Resolution: Go to phone Settings → Apps → Special app access → Install unknown apps → select your File Manager → enable "Allow from this source".

3. Signature Conflict with an Earlier Build

Android will reject the installation if an older test version is already installed with a conflicting certificate.

Resolution: Go to Settings → Apps → KAAVAL → Uninstall. When prompted, ensure "Keep app data" is unchecked before installing.
